::# /plan TARGET TASK...: every checked model plans TASK into its own file, then the coordinator
::# picks the best plan as a base and improves it using all plans. /plan-full refines the plans
::# in more steps. PLAN_DIR comes from [commands.variables] in the config.
::#
::# Example: /plan PS-12000 implement https://perconadev.atlassian.net/browse/PS-12000
::#
::# Example: /plan PS-11940-merge-26.10 implement option B PLAN_DIR=/tmp/plans
::args TARGET TASK...

::# 1. Every model writes its own plan
::send all
OUTPUT_FILE=$PLAN_DIR/plan-$MODEL_ID.md
In $OUTPUT_FILE create a plan to $TASK
::wait-model-files $OUTPUT_FILE

::# 2. The coordinator picks the best plan as a base and improves it using all plans
::send $COORDINATOR
PLAN_FILES=$PLAN_DIR/plan-*.md
OUTPUT_FILE=$PLAN_DIR/plan2-final-$MODEL_ID.md
Select the best plan from $PLAN_FILES as a base, improve it using the other plans and create $OUTPUT_FILE
Rank plans at the end.
::wait-model-files $OUTPUT_FILE
