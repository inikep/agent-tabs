::# /plan-full TARGET TASK...: every checked model plans TASK into its own file, then in four
::# more steps improves its plan using all plans, compares the plans, improves its plan using
::# the comparisons, and picks the best plan as a base and improves it. /plan is the short
::# version. PLAN_DIR comes from [commands.variables] in the config.
::#
::# Example: /plan-full PS-12000 implement https://perconadev.atlassian.net/browse/PS-12000
::#
::# Example: /plan-full PS-11940-merge-26.10 implement option B PLAN_DIR=/tmp/plans
::args TARGET TASK...

::# 1. Every model writes its own plan
::send all
OUTPUT_FILE=$PLAN_DIR/plan1-$MODEL_ID.md
Don't build, and don't run tests or the server; plan from the code and git history only.
In $OUTPUT_FILE create a plan to $TASK
::wait-model-files $OUTPUT_FILE

::# 2. Every model improves its plan using all plans
::send all
PLAN_FILES=$PLAN_DIR/plan1-*.md
OUTPUT_FILE=$PLAN_DIR/plan2-$MODEL_ID.md
Don't build, and don't run tests or the server; plan from the code and git history only.
Improve your plan using all plans in $PLAN_FILES and create $OUTPUT_FILE
::wait-model-files $OUTPUT_FILE

::# 3. Every model compares the improved plans
::send all
PLAN_FILES=$PLAN_DIR/plan2-*.md
OUTPUT_FILE=$PLAN_DIR/plan3-compare-$MODEL_ID.md
Don't build, and don't run tests or the server; plan from the code and git history only.
Compare correctness of all plans in $PLAN_FILES and create $OUTPUT_FILE
::wait-model-files $OUTPUT_FILE

::# 4. Every model improves its plan using the comparisons
::send all
PLAN_FILES=$PLAN_DIR/plan3-compare-*.md
OUTPUT_FILE=$PLAN_DIR/plan4-$MODEL_ID.md
Don't build, and don't run tests or the server; plan from the code and git history only.
Improve your plan based on $PLAN_FILES and create $OUTPUT_FILE
::wait-model-files $OUTPUT_FILE

::# 5. Every model picks the best plan as a base and improves it
::send all
PLAN_FILES=$PLAN_DIR/plan4-*.md
OUTPUT_FILE=$PLAN_DIR/plan5-$MODEL_ID.md
Don't build, and don't run tests or the server; plan from the code and git history only.
Select the best plan from $PLAN_FILES as a base, improve it and create $OUTPUT_FILE
::wait-model-files $OUTPUT_FILE
