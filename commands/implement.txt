::# /implement BASE_BRANCH PLAN [NOTES...]: every checked model creates its own branch
::# BASE_BRANCH-MODEL_ID on top of BASE_BRANCH and implements PLAN there, following implement.md
::# next to this file. The coordinator then compares the branches and builds BASE_BRANCH-final
::# on the best one, improved from the comparison. Both arguments may also be given as
::# BASE_BRANCH=… PLAN=…; NOTES go to every model after the instructions. IMPLEMENT_DIR, where
::# the summaries and the comparison go, comes from [commands.variables] in the config.
::#
::# The models work from SOURCE_DIR, the git checkout with BASE_BRANCH, by default the directory
::# agent-tabs runs in. SOURCE_DIR=/path before NOTES changes it.
::#
::# Example: /implement PS-12000-8.4 /work/LLM-plans/PS-12000/plan2-final-Opus-5.5-high.md
::#
::# Example: /implement PS-11299-trunk PLAN=/work/LLM-plans/PS-11299-port-vector/plan5-Opus-5.5-high.md
::args BASE_BRANCH PLAN [NOTES...]

::# 1. Every model implements the plan on its own branch
::send all
OUTPUT_FILE=$IMPLEMENT_DIR/implement-$MODEL_ID.md
Read environment rules from $PROMPT_DIR/environment.md
Read instructions from $PROMPT_DIR/implement.md
$NOTES
::wait-model-files $OUTPUT_FILE

::# 2. The coordinator compares implementations (branches)
::send $COORDINATOR
IMPLEMENT_FILES=$IMPLEMENT_DIR/implement-*.md
OUTPUT_FILE=$IMPLEMENT_DIR/compare-$MODEL_ID.md
IMPLEMENT_RANKING=$IMPLEMENT_DIR/compare-ranking-$MODEL_ID.md
Read environment rules from $PROMPT_DIR/environment.md
Read instructions from $PROMPT_DIR/implement-compare.md
Rank implementations and write to $IMPLEMENT_RANKING with duration.
$NOTES
::wait-model-files $OUTPUT_FILE

::# 3. The coordinator selects the best base branch and improves it using the comparison
::send $COORDINATOR
COMPARE_FILE=$IMPLEMENT_DIR/compare-$MODEL_ID.md
OUTPUT_FILE=$IMPLEMENT_DIR/final-$MODEL_ID.md
Read environment rules from $PROMPT_DIR/environment.md
Read instructions from $PROMPT_DIR/implement-improve.md
$NOTES
::wait-model-files $OUTPUT_FILE
